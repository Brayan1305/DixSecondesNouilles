# Site vitrine - Dix Secondes Nouilles

## Description
Projet de site vitrine pour le restaurant Dix Secondes Nouilles à Paris.

## Structure des fichiers
- `index.html` : Page principale du site
- `styles.css` : Feuilles de style
- `images/` : Dossier contenant les médias du projet

## Comment lancer le projet
Ouvrir le fichier `index.html` dans un navigateur web (Chrome, Safari, Firefox).
